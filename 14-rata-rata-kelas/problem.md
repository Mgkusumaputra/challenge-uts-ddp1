# Rata-rata Kelas

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 18 minutes  
**Topics:** Lists, loops, functions

## Problem Statement

Diberikan N nilai ujian. Cetak rata-rata dengan tepat dua angka di belakang koma. Gunakan fungsi `rata_rata(data)` yang mengembalikan rata-rata list.

## Input Format

Baris pertama N. Baris kedua berisi N nilai.

## Output Format

Rata-rata dengan dua angka desimal.

## Constraints

1 ≤ N ≤ 100000; 0 ≤ nilai ≤ 100

## Sample Input 0
```text
4
80 75 90 95
```

## Sample Output 0
```text
85.00
```

## Explanation 0

Pastikan pembagian menghasilkan float dan format output selalu dua desimal.
