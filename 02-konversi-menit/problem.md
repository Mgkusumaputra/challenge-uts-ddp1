# Konversi Durasi

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 10 minutes  
**Topics:** Variables, integer division, modulo

## Problem Statement

Diberikan durasi dalam detik. Ubah menjadi jam, menit, dan detik tersisa.

## Input Format

Satu bilangan bulat `s` (detik).

## Output Format

Cetak `jam menit detik` dengan spasi.

## Constraints

0 ≤ s ≤ 10^7

## Sample Input 0
```text
3671
```

## Sample Output 0
```text
1 1 11
```

## Explanation 0

Gunakan // untuk pembagian bulat dan % untuk sisa pembagian.
