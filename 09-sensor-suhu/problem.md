# Sensor Suhu

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 15 minutes  
**Topics:** Lists, conditionals, aggregation

## Problem Statement

Sebuah sensor mencatat N suhu. Hitung berapa pengukuran yang berada di luar rentang aman inklusif 18 sampai 30 derajat, yaitu kurang dari 18 atau lebih dari 30.

## Input Format

Baris pertama N. Baris kedua berisi N bilangan bulat suhu.

## Output Format

Cetak jumlah pengukuran di luar rentang aman.

## Constraints

1 ≤ N ≤ 100000; -50 ≤ suhu ≤ 100

## Sample Input 0
```text
5
18 17 25 31 30
```

## Sample Output 0
```text
2
```

## Explanation 0

Batas 18 dan 30 masih aman karena rentangnya inklusif.
