# Total Belanja

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 12 minutes  
**Topics:** Loops, accumulator

## Problem Statement

Input berisi N, lalu N bilangan bulat yang menyatakan harga barang. Hitung total harga semua barang.

## Input Format

Baris pertama N. Baris kedua berisi N bilangan bulat.

## Output Format

Cetak total harga.

## Constraints

1 ≤ N ≤ 10^4; 0 ≤ harga ≤ 10^6

## Sample Input 0
```text
4
12000 5000 3000 10000
```

## Sample Output 0
```text
30000
```

## Explanation 0

Gunakan accumulator yang dimulai dari nol.
