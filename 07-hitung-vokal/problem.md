# Hitung Vokal

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 12 minutes  
**Topics:** Strings, loops, membership

## Problem Statement

Diberikan satu baris teks. Hitung jumlah huruf vokal `a, i, u, e, o`, tanpa membedakan huruf besar dan kecil.

## Input Format

Satu baris teks.

## Output Format

Satu bilangan jumlah vokal.

## Constraints

Panjang teks 1 sampai 10000.

## Sample Input 0
```text
DDP itu seru!
```

## Sample Output 0
```text
4
```

## Explanation 0

Ubah teks ke huruf kecil, lalu cek tiap karakter.
