# Lulus atau Remedial

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 10 minutes  
**Topics:** Conditionals, comparison operators

## Problem Statement

Nilai akhir mahasiswa berupa bilangan bulat 0 sampai 100. Cetak `LULUS` jika nilainya minimal 60, selain itu cetak `REMEDIAL`.

## Input Format

Satu bilangan bulat n.

## Output Format

`LULUS` atau `REMEDIAL`.

## Constraints

0 ≤ n ≤ 100

## Sample Input 0
```text
60
```

## Sample Output 0
```text
LULUS
```

## Explanation 0

Batas 60 termasuk lulus. Uji juga nilai 59 dan 60.
