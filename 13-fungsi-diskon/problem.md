# Fungsi Diskon

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 15 minutes  
**Topics:** Functions, conditionals

## Problem Statement

Buat program yang menghitung harga setelah diskon. Diskon 10% berlaku jika total belanja minimal Rp100.000; selain itu tidak ada diskon. Input satu total belanja. Cetak harga akhir sebagai bilangan bulat dengan pembulatan ke bawah.

## Input Format

Satu bilangan bulat total belanja.

## Output Format

Satu bilangan bulat harga akhir.

## Constraints

0 ≤ total ≤ 10^9

## Sample Input 0
```text
150000
```

## Sample Output 0
```text
135000
```

## Explanation 0

Pisahkan aturan perhitungan ke dalam fungsi yang mengembalikan hasil.
