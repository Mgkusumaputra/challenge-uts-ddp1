# Ringkasan Baris

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 20 minutes  
**Topics:** Text files, strings, split

## Problem Statement

Simulasikan ringkasan file teks. Input terdiri dari N baris teks. Hitung total jumlah kata dari seluruh baris, dengan kata didefinisikan sebagai potongan yang dipisahkan oleh whitespace. Baris kosong tidak memiliki kata.

## Input Format

Baris pertama N, diikuti N baris teks.

## Output Format

Cetak total kata.

## Constraints

0 ≤ N ≤ 10000; panjang setiap baris ≤ 10000.

## Sample Input 0
```text
3
DDP satu

belajar Python bersama
```

## Sample Output 0
```text
5
```

## Explanation 0

Dalam challenge ini, baris teks diberikan melalui stdin; tidak perlu membuka file di sistem.
