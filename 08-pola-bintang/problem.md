# Pola Bintang

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 10 minutes  
**Topics:** Repetition, nested loops

## Problem Statement

Diberikan bilangan N. Cetak segitiga rata kiri dengan baris ke-i berisi i karakter `*`, untuk i dari 1 sampai N.

## Input Format

Satu bilangan bulat N.

## Output Format

N baris pola bintang.

## Constraints

1 ≤ N ≤ 100

## Sample Input 0
```text
4
```

## Sample Output 0
```text
*
**
***
****
```

## Explanation 0

Setiap baris dapat dibentuk dengan mengulang string bintang sebanyak i kali.
