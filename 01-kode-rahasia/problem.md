# Kode Rahasia

**Difficulty:** Easy  
**Points:** 10  
**Estimated time:** 10 minutes  
**Topics:** Variables, input/output, arithmetic

## Problem Statement

Sebuah pesan rahasia dienkripsi dengan mengalikan setiap angka dengan 3 lalu menambahkan 2. Diberikan satu bilangan bulat `n`, cetak nilai hasil enkripsi tersebut.

## Input Format

Satu bilangan bulat n.

## Output Format

Satu bilangan bulat hasil enkripsi.

## Constraints

-10^6 ≤ n ≤ 10^6

## Sample Input 0
```text
5
```

## Sample Output 0
```text
17
```

## Explanation 0

Perhatikan urutan operasi: kalikan tiga, lalu tambah dua.
