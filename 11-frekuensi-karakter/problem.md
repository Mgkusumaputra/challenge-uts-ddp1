# Frekuensi Karakter

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 18 minutes  
**Topics:** Strings, loops, dictionaries not required

## Problem Statement

Diberikan sebuah baris teks dan sebuah karakter c. Hitung banyak kemunculan c pada teks, dengan membedakan huruf besar dan kecil.

## Input Format

Baris pertama teks. Baris kedua satu karakter c.

## Output Format

Cetak frekuensi c.

## Constraints

Teks panjang 1 sampai 100000; c satu karakter.

## Sample Input 0
```text
Banana
a
```

## Sample Output 0
```text
3
```

## Explanation 0

Bandingkan setiap karakter secara langsung agar kapitalisasi tetap dibedakan.
