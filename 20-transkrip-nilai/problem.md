# Transkrip Nilai

**Difficulty:** Hard  
**Points:** 30  
**Estimated time:** 25 minutes  
**Topics:** Lists, conditionals, loops, aggregation

## Problem Statement

Diberikan N nilai mahasiswa. Kategorikan setiap nilai: A untuk 85–100, B untuk 70–84, C untuk 55–69, D untuk 40–54, dan E untuk di bawah 40. Cetak jumlah mahasiswa untuk kategori A, B, C, D, E dalam urutan tersebut.

## Input Format

Baris pertama N. Baris kedua berisi N nilai.

## Output Format

Cetak lima bilangan yang dipisahkan spasi: jumlah A B C D E.

## Constraints

1 ≤ N ≤ 100000; 0 ≤ nilai ≤ 100.

## Sample Input 0
```text
7
90 85 72 68 54 39 100
```

## Sample Output 0
```text
3 1 1 1 1
```

## Explanation 0

Urutkan kondisi dari batas tertinggi ke terendah agar setiap nilai masuk tepat ke satu kategori.
