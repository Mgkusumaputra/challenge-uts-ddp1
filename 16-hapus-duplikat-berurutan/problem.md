# Hapus Duplikat Berurutan

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 20 minutes  
**Topics:** Lists, loops, indexing

## Problem Statement

Diberikan list bilangan. Buat list baru dengan menghapus elemen yang sama dengan elemen tepat sebelumnya. Duplikat yang tidak bersebelahan tetap dipertahankan.

## Input Format

Baris pertama N. Baris kedua N bilangan bulat.

## Output Format

Cetak elemen hasil dipisahkan spasi.

## Constraints

1 ≤ N ≤ 100000.

## Sample Input 0
```text
8
1 1 2 2 2 1 3 3
```

## Sample Output 0
```text
1 2 1 3
```

## Explanation 0

Bandingkan hanya dengan elemen terakhir hasil, bukan semua elemen sebelumnya.
