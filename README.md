# DDP 1 Midterm Prep — HackerRank Challenge Pack

This package contains 24 original Python 3 coding challenges based on the uploaded DDP 1 lecture materials. The past exam PDFs were supplied as calibration context; the problems here are newly written rather than copied verbatim.

## Mix
- 8 Easy, 10 Medium, 6 Hard
- Primary language: Bahasa Indonesia, with English technical terms and selected English naming
- 24 problem statements, reference solutions, sample cases, and an additional edge test per problem

## Important platform note
This pack is ready for manual entry into HackerRank, but it is not a native HackerRank import file. For each challenge, open `problem.md` and paste the statement into HackerRank. Add the sample input/output in the sample section, then create private test cases using `tests.txt`. Put `solution.py` in your private editorial/reference solution area, not the public statement. HackerRank's available fields vary by product (Practice, Contest, or custom test).

## Recommended setup
- Contest title: **DDP 1 Midterm Sprint: From Basics to Brain-Burners**
- Language: Python 3 only, if the goal is syllabus-aligned preparation
- Suggested duration: 150 minutes for a full contest; alternatively publish as a practice set with no hard deadline
- Suggested scoring: use the points in each problem (Easy 10, Medium 20, Hard 30); total 460 points
- Reveal editorial/reference solutions after the competition closes, if desired

## Syllabus alignment
Challenges cover input/output and expressions, number systems, conditionals, loops, strings, text-line processing, exception handling, functions, and lists. Text-file challenge 18 uses stdin lines to keep the problem compatible with online judge sandboxing; students do not need filesystem access.
