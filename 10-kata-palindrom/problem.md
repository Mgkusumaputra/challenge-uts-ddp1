# Palindrom Sederhana

**Difficulty:** Medium  
**Points:** 20  
**Estimated time:** 15 minutes  
**Topics:** Strings, slicing, conditionals

## Problem Statement

Diberikan sebuah kata yang hanya terdiri dari huruf latin. Cetak `YA` jika kata tersebut sama ketika dibaca dari depan maupun belakang, selain itu cetak `TIDAK`. Pengecekan tidak membedakan kapitalisasi.

## Input Format

Satu kata.

## Output Format

`YA` atau `TIDAK`.

## Constraints

Panjang kata 1 sampai 100000.

## Sample Input 0
```text
KasurRusak
```

## Sample Output 0
```text
YA
```

## Explanation 0

Bandingkan string yang sudah dinormalisasi dengan versi terbaliknya.
